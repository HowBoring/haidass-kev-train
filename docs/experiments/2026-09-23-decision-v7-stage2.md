# Decision-v7 与 typed-decisions 阶段二：实验记录

**记录日期：**2026-09-23。**状态：**以下运行与开发集评估已完成；本文是对既有工件的整理，不是一次新训练。研究问题是：Haidass1.5-143M 的第一阶段训练预算、调度和更新范围是否改善同源与跨源决策，以及在同一第一阶段起点上增加阶段二目标是否保留 Kev 能力。

## 先看结论

- **第一阶段：**种子 42 的长预算 LoRA 检查点同源（ID）准确率为 **68.35%**，高于原始短训的 **66.46%**；跨源（OOD）准确率却由 **53.05%** 降为 **50.61%**。因此保留原始短训检查点作为本地跨源参照，不将“同源最好”写成“整体最好”。
- **重复性：**长训相对短训的同源开发集按任务等权 NLL 在种子 42/43/44 中分别变化 **−0.035 / +0.027 / −0.031**；只有 **2/3** 个种子改善。最优检查点均早于训练预算末步。
- **阶段二：**D（交叉熵 + RLCD）教师目标题的 NLL **1.094**，低于 B（仅交叉熵）的 **1.104**、C（交叉熵 + 直接评分损失）的 **1.100**，但 B/C/D 的 Kev 跨源准确率均低于共同起点 A。尚未满足政策决策的 RLCD 进入门槛。

完整数表、指标推导与外部基准来源见[实验结果报告](../research/kev-aligned-experiment-report.md)、[Kev 原始来源核对](../research/kev-benchmark-source-notes.md)；供阅读的单文件[图文报告](../../index.html)含实验过程、六图及三张结果表。下文只记录未来研究需要沿用的控制条件、选择和失败边界。

## 比较口径与固定条件

- **本地底座：**Haidass1.5-143M 的共享状态、分支隔离与选项指针读出，不生成答案文本。阶段一采用从 Kev `decision-v7` 中选出的十个公开来源及 `compositional`，**不含 `legacy_policy`**；使用在线增强。配置以[搜索汇总工件](../../artifacts/comparisons/sft-exploration/summary.json)中的 `fixed_contract` 为准：有效批量 16，余弦调度的长预算 4,380 步，指针头学习率 2e-4。旧 v6 检查点只有历史参考意义，不是 v7 调度器的匹配对照。
- **选择规则：**各阶段一运行各自按 BF16 的 `decision-v7` 开发集 `clean` **任务等权 NLL** 选检查点；阶段二 B/C/D 各自按 BF16 typed-decisions 开发集**未校准 NLL**选检查点。Kev 跨源成绩仅作选后诊断，未参与两阶段选模。
- **对外比较规则：**同源 `decision-v7` 开发集 **1,264 道**、跨源 `transfer-v4` 开发集 **656 道** `clean` 已标注题；官方评分器在 FP32、温度 1、日期事实关闭条件下按**题目等权**给出准确率、NLL、多类 Brier。Kev 行是其公开开发集成绩，不是本地重跑。BF16 选模 NLL、FP32 官方按题 NLL、阶段二教师目标 NLL 不应互作同一指标。固定 Kev 代码提交 `90990a5fac2995b9faa3190f7d437e84f2067768`、套件修订 `a957287d1c502a4e2e3b9d9d1325c2c6f27f181c`；哈希与评分约定见[评分器来源工件](../../artifacts/reports/kev-official-comparison/provenance.json)。

## 按实验顺序记录

### 1. v7 短预算调度器

**控制：**相同的 v7 训练来源、增强、LoRA 学习率 2e-4、种子 42、最多 2,190 次更新，只变更余弦与 OneCycle 调度。余弦在第 2,190 步选出（开发集任务等权 NLL **0.7989**），OneCycle 在第 1,800 步选出（**0.8124**）；相应官方 FP32 同源 / 跨源准确率为 **66.46% / 53.05%** 和 **65.90% / 51.37%**。这是单一种子的受控调度对照，不推出一般性的调度器优劣。[调度器协议与结果](../../artifacts/reports/v7-scheduler-comparison/summary.json) · [官方评分](../../artifacts/reports/v7-scheduler-comparison/official-fp32.json)。

**命名决议：**此后的“阶段一基线 A”固定指种子 42 的余弦检查点 `artifacts/checkpoints/decision-v7-aug-cosine/step-002190`（工件 SHA-256 `bfcb36f770eef7caf981ab52cbb16e2b0cb21698dc13e5762ee6fb51df78cf9e`）。A 不是外部教师，也不是同源最佳的长训检查点。

### 2. 阶段一更新范围、学习率与预算

**控制：**固定同一训练来源、增强、余弦调度和种子 42，将预算上限设为 4,380 步；比较 LoRA `2e-4` / `1e-4` 和全参数 `5e-5` / `2e-5`。按 BF16 开发集任务等权 NLL 排序的**选中检查点**分别为 `0.7639`（第 3,000 步）、`0.8297`（第 3,000 步）、`0.7835`（第 3,000 步）、`0.8767`（第 4,200 步）；旧短预算 LoRA `2e-4` 为 `0.7989`。以上数值不是官方 FP32 按题 NLL。[逐运行选择与配置](../../artifacts/comparisons/sft-exploration/summary.json)。

**选择和观察：**继续调查长预算 LoRA `2e-4`，并将全参数 `5e-5` 一起送入官方 FP32 对照；另外两条较弱路线没有单独的官方 FP32 结果。长预算 LoRA 种子 42 在第 3,000 步的选模 NLL 为 **0.7639**，到第 4,380 步变为 **0.8094**，尽管训练探针损失继续下降：保留早期选中检查点，而不把预算末步当成改进。其官方 FP32 同源 NLL / Brier **0.720 / 0.396**（A 为 **0.775 / 0.425**），跨源准确率 / Brier **50.61% / 0.561**（A 为 **53.05% / 0.549**）。[官方 FP32 汇总](../../artifacts/reports/sft-exploration/summary.json)。

### 3. 配对种子与不确定性

**控制：**对种子 42、43、44，长、短预算 LoRA `2e-4` 均独立按同源开发集 NLL 选检查点，再在**相同种子内**计算长减短的 BF16 差值。NLL 变化为 **−0.035、+0.027、−0.031**；同源 BF16 准确率变化为 **+1.82、+0.79、+0.55 个百分点**。长训选中步数为 **3,000、2,000、1,800**。仅有三个种子，这些差值是描述性结果。[匹配运行及配对差值](../../artifacts/comparisons/sft-exploration/summary.json)。

**同种子 FP32 对比：**长训种子 42 减基线 A，同源准确率 **+1.90 个百分点**，跨源 **−2.44 个百分点**。按来源分层、保留同一原始记录下题目的 2,000 次配对簇重抽样得到 95% 区间：同源准确率 **[−0.24, +3.96]**，跨源 **[−5.79, +0.77]** 个百分点；同源 Brier 差 **−0.029 [−0.040, −0.017]**，跨源 **+0.012 [−0.001, +0.025]**。这些区间反映题目抽样，**不是跨训练种子的置信区间**。[逐项机器可读区间](../../artifacts/reports/sft-exploration/paired-fp32-long-seed42-minus-original.json)。

### 4. 阶段二教师目标与目标函数

**共同起点与数据：**A 是第 1 项定义的 2,190 步检查点。[typed-decisions 数据卡](https://huggingface.co/datasets/LocalLLaMA/typed-decisions/raw/main/README.md)说明，`gold` 是教师端点对每例采样三次后平均的概率分布，不是独立核验的真值。[本地数据转换](../../src/haidass_kev_train/training/typed_decisions.py)将预存的 `gold.probabilities` 作为 `target`；这是离线软目标蒸馏，**不是**以 Laya 检查点初始化 A，也不是训练时每步查询教师。按案例分为 960 训练 / 120 开发 / 120 校准，每例五题；开发集含 600 道教师目标题。

**对照设计：**B 为交叉熵 + 阶段一回放；C 在 B 上加入直接可微的适当评分损失；D 在 B 上加入 logits 空间高斯噪声的 RLCD。B/C/D 从同一 A 出发，均训练 300 次更新，仅附加损失不同。[阶段二训练约定](../agents/training.md#running-stage-2) · [四路线工件与精度](../../artifacts/comparisons/stage2/summary.json)。

| 路线 | 教师目标 BF16 原始 NLL ↓ | 教师首选项一致率 | Kev 同源 FP32 准确率 | Kev 跨源 FP32 准确率 |
|---|---:|---:|---:|---:|
| A · 阶段一基线 | 1.493 | 31.17% | 66.46% | 53.05% |
| B · CE + 回放 | 1.104 | 50.00% | 65.66% | 49.70% |
| C · CE + 直接评分损失 + 回放 | 1.100 | 51.17% | 66.14% | 49.24% |
| D · CE + RLCD + 回放 | 1.094 | 51.00% | 65.74% | 49.70% |

教师首选项一致率测的是与**教师概率最高选项**的一致，而不是独立验证的正确率。D 相比 C 的教师目标 NLL 改进约 **0.0069**，单个种子；D 相比 A 的 Kev 跨源准确率下降 **3.35 个百分点**。在 180 次选项重排测试中，**各自校准后**的答案翻转率 A/B/C/D 为 **16.7% / 43.9% / 42.8% / 45.6%**，说明教师目标拟合的改善并未换来选项顺序稳定性。A 在需要随政策变化改变答案的题对上，两题都正确仅同源 **1/80**、跨源 **0/64**；题对数不等于 clean 题数。阶段二因此是工程对照，而非通过 RLCD 政策能力门槛的结果。

## 当前判定与后续研究入口

1. **已完成的比较：**v7 调度器单种子、四条种子 42 长预算配方、三种子长短预算配对、同一 A 出发的 B/C/D 阶段二目标对照、官方 FP32 开发集评分及种子 42 的题目簇重抽样。
2. **尚不能声称：**稳定的长预算收益、RLCD 的跨源收益、政策能力达标、与 Kev 的架构控制变量因果差距，或本轮模型有锁定测试集成绩。旧版 v6 曾有历史测试评估；“本轮未用锁定测试选模”不等于“项目从未读过测试集”。Kev-0.6B 公开开发集为同源 **80.1%**、跨源 **62.0%**，但其底座和训练来源与本地不同。[跨项目口径说明](../research/kev-aligned-experiment-report.md#interpretation-and-limits)。
3. **下一轮开始前的门槛：**先明确要优化的是同源概率、跨源迁移还是政策相关题对能力；保留 A 作为跨源参照，按种子成对比较新配方，报告选模指标与官方 FP32 口径，并继续在开发阶段隔离锁定测试。若研究 RLCD 的实际收益，先检查政策题对的两题正确率是否跨过拟定能力门槛，再比较目标函数；当前 1/80 和 0/64 不支持进入结论。这里是**待研究问题与判据**，不是新增实验已完成的宣称。
